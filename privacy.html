rclone Privacy Policy

Last updated: October 7, 2026

Overview

This application, rclone, is a personal application used by its owner to manage and synchronize files with supported cloud storage services.

Information We Access

Depending on the cloud storage service being used, rclone may access files, folders, file metadata, and account information necessary to perform file synchronization and storage management.

How Information Is Used

Information accessed through the application is used only to provide the requested file management, synchronization, upload, download, and storage operations.

Data Sharing

We do not sell personal information. Information accessed by the application is not shared with third parties except where necessary to operate the requested cloud storage service.

Data Storage

The application is intended for personal use. Data may be temporarily processed or stored as necessary to perform the requested operations.

Data Security

Reasonable measures are used to protect credentials and information used by the application. Users should also protect their own devices and authentication credentials.

Contact

For questions about this privacy policy, please contact the application owner.
